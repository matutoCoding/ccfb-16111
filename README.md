# 塔式夹具装夹与可达性校验系统

浏览器端 TypeScript + three.js 应用,用于卧式加工中心/塔式夹具的装夹布局与刀具可达性校验。
所有数据保存在浏览器 IndexedDB,无需后端。

## 启动

```bash
npm install
npm run dev        # 开发服务器(http://127.0.0.1:5180)
npm run build      # 类型检查 + 生产构建
npm run selftest   # Node 端判定数学单元测试(25 项)
```

## 五个页面

1. **元件库**:塔柱、定位销、压板、支承钉、液压缸等参数化元件(尺寸可编辑,T 型槽/网格孔位吸附);
   刀具库(刀号、刀杆/刀柄直径、刃长、刀柄长);工件参数化阀体/泵壳生成与 STL 二进制导入。
2. **装夹布置**:元件按塔面网格吸附,工件定位面自动贴合;3-2-1 定位校验(缺定位销/支承钉实时提示);
   实例微调(槽位、旋转、三轴偏移),改动触发可达性增量重算。
3. **加工特征**:点选三维特征,孔/端面/螺纹孔/沉孔四类,每特征可挂多把刀;六向加工方向。
4. **可达性校验**:B=0..360 每 5° 扫描,72×N 可达矩阵热力图;推荐一次装夹覆盖最多特征的角度;
   压板遮挡关系明细;最短不干涉刀长。
5. **工艺卡**:按推荐 B 角分工步,列特征/刀号/最短刀长,附每角度三维截图,可导出 JSON。

## 可达性引擎(核心)

`src/core/reachEngine.ts` 实现两级级联正交深度图:

- **细级联(刀杆包络)**:半宽 = 刀半径 + 0.8mm,128px 下约 0.036mm/像素,保证 3mm 孔周边不误判。
- **粗级联(刀柄环形包络)**:半宽 = 刀柄半径 + 2mm,JS 端读 64×64 首池并剔除刀杆内圈,只检测环带。
- 线性清除距离渲染到 **RGBA32F 浮点纹理**(WebGL2 + EXT_color_buffer_float),无 8bit 量化误差。
- 实例 ID 经 R8 颜色通道回读,遮挡单元格可反查到具体压板/工件。
- 特征自身工件从障碍集剔除(刀进孔是设计内行为)。

### 判定阈值(`src/core/reachMath.ts`)

- 间隙 ≥ 0.5mm:判可达
- 间隙 ≤ -0.2mm(侵入 0.2mm):判挡住
- 之间为临界带,给出可达结论但标注"建议复核",杜绝亚毫米误判

### 刀长可行区间

对每把刀分别计算刀杆柱体(长 L、半径 rTool)与刀柄柱体(前端在 L-lh、半径 rHolder)
在深度方向的约束,输出最短不干涉刀长与区间为空的原因。

## 性能

- 单角度全量约 20-30 次 GPU 渲染 + 回读;独立显卡单角 30-100ms,72 角数秒级。
- 压板挪动后仅重算受影响特征(CPU AABB 预筛 + 单角增量),满足 100ms 交互目标。
- 软件渲染(SwiftShader)环境会慢约 20-30 倍,属预期。
